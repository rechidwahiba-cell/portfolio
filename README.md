# Portfolio of Wahiba Rechid

Live site: **[wahiba-rechid.vercel.app](https://wahiba-rechid.vercel.app/)**

I am a go-to-market, marketing and communications manager. This is the site where I show my work: four stories about product launches, brand strategy and organic growth.

## How it is built

- One page of plain HTML, CSS and JavaScript: no framework, no build step
- Charts drawn in SVG by a small script, with no charting library
- Responsive, with reduced-motion support and search and sharing metadata
- Hosted on Vercel: every change pushed to this repository goes live in under a minute

I wrote the content, directed the design and shipped the site myself, working with an AI coding assistant.
